# 💬 Customer Review Sentiment Analyzer

> Day 3 Project - AI Workshop by C2C Tech Solutions Pvt Ltd

An AI-powered web application that classifies customer reviews into **Positive, Neutral, and Negative** sentiments using Natural Language Processing (NLP).

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Streamlit](https://img.shields.io/badge/Framework-Streamlit-red)
![ML](https://img.shields.io/badge/ML-TF--IDF%20%2B%20Logistic%20Regression-green)

### 🔗 Live Demo
http://localhost:8501

### 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-learn, Matplotlib
- **NLP Techniques:** TF-IDF Vectorization
- **ML Model:** Logistic Regression
- **Frontend:** Streamlit
- **Dataset:** Customer Review Dataset (CSV)

### ✨ Key Features
- ✅ Predict sentiment from single review text
- ✅ Analyze multiple reviews via CSV upload (Batch Analysis)
- ✅ Visualize sentiment distribution with bar charts
- ✅ Download analyzed results
- ✅ Handles Positive, Negative & Neutral classes
